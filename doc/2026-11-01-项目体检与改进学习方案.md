## 一、项目是什么

尚硅谷《谷粒商城》微服务实战课程的完整代码（个人 fork，作者 AdverseQ）：

| 项     | 内容                                                                         |
|--------|------------------------------------------------------------------------------|
| 时间线 | 2021-02-22 建仓 → 2022-05-04 最后提交（「排除bug02」），此后 4 年多未动      |
| 规模   | 74 提交 / 单 master 分支 / 约 15 个 Maven 模块 / 667 个 Java 文件 / 17MB     |
| 形态   | **纯后端**，无前端（课程前端是独立仓库 gulimall-vue / renren-fast-vue）      |
| 性质   | 电商全链路教学项目：商品、检索、购物车、订单、库存、会员、优惠券、秒杀、支付 |

### 核心业务设计（学习重点）

1. **商品**：三级分类缓存（Redis）+ 缓存一致性（双删/过期）、SPU/SKU 多表、属性分组
2. **检索**：ES 索引（`dsl.json` / `product-mapping.txt` 在仓库内）、商品上架同步 ES
3. **购物车**：Redis 存储 + Spring Session 登录态共享、Feign 远程调商品/库存
4. **订单**：Feign 链路（会员/商品/库存）、库存锁定（Redis 预扣 + DB 锁定）、**RabbitMQ 延时队列关单补偿**、支付回调幂等、库存解锁 MQ 消费者
5. **秒杀**：定时上架（提前 3 天）、Redis 预减库存、信号量限流、MQ 异步创建订单、防重复购买
6. **后台管理（已移除）**：原 renren-fast（RBAC）+ renren-generator 脚手架，属课程附赠组件，2026-11-01 决策移除（见文末「决策记录」）
7. **分布式事务**：**无 Seata**，用「本地事务 + MQ 最终一致性 + 定时补偿」——这正是课程的设计点

### 阶段 1：版本现代化（✅ 已拍板：路线 B 彻底现代化）

**定案版本矩阵**（2026-11-01 对照官方 Release Notes / 2023.x 分支 README 核实）：

| 组件                   | 定案版本                                                                         | 依据 / 备注                                                                               |
|------------------------|----------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------|
| Java                   | **17**（LTS）                                                                    | SCA 2023.x 分支官方要求 JDK 17+                                                           |
| Spring Boot            | **3.2.x**（≥3.2.4）                                                              | SCA 官方适配表：2023.0.1.0 ↔ Boot 3.2.4                                                   |
| Spring Cloud           | **2023.0.x**（2023.0.1）                                                         | 同上，官方配套                                                                            |
| Spring Cloud Alibaba   | **2023.0.x**（最新补丁线 2023.0.3.x，README 示例 2023.0.3.4）                    | 用 BOM 统一管理，替换 common 里的 2.1.0.RELEASE                                           |
| Nacos（服务端+客户端） | **2.3.x**（SCA 2023.0.x 适配 2.3.2）                                             | 配置中心迁移到 `spring.config.import`（或加 `spring-cloud-starter-bootstrap` 兼容旧写法） |
| Sentinel               | 1.8.6（随 SCA BOM）                                                              | 规则持久化到 Nacos                                                                        |
| MyBatis-Plus           | **3.5.x**（须用 `mybatis-plus-spring-boot3-starter`）                            | 3.2.0 不兼容 Boot 3                                                                       |
| Elasticsearch          | `elasticsearch-java` 8.x（官方 Java API Client）或 spring-data-elasticsearch 5.x | high-level client 已废弃                                                                  |
| Swagger                | springdoc-openapi 2.x                                                            | springfox 停维护且不兼容 Boot 3                                                           |
| fastjson               | 删除，统一 Jackson（Boot 自带）                                                  | 🔴 RCE 漏洞，必清                                                                         |
| lombok                 | 1.18.30+                                                                         | 兼容 Java 17                                                                              |

**主要改造点清单**：`javax.* → jakarta.*`（全量替换，机械但量大）、SpringFox → springdoc-openapi、ES high-level → Java API Client、Fastjson → Jackson、Nacos 配置改 `spring.config.import`、Sentinel 规则持久化、Redis 连接（Boot 3 默认 Lettuce，无需改）。

**升级顺序（按模块逐个，每步独立编译跑通再下一个）**：common（依赖基座，全家受影响，放最前）→ gateway → product → member/coupon/ware → order/search/cart → seckill → auth/third-part → 最后统一清 SSO demo。ES/RabbitMQ 客户端升级影响面集中在 search/order/seckill，单独批次处理。

**依赖替换清单（无论哪条路线）**

| 现依赖                              | 替换为                               | 优先级              |
|-------------------------------------|--------------------------------------|---------------------|
| fastjson 1.2.15                     | Jackson（Boot 自带）/ Gson           | 🔴 最高（RCE）      |
| springfox 2.9.2                     | springdoc-openapi                    | 🟠 高（Boot3 必须） |
| ES high-level client 7.4.2          | Java API Client 8.x / spring-data-es | 🟠 高               |
| commons-lang 2.6 / httpclient 4.2.1 | commons-lang3 / Boot 自带            | 🟡 中               |
| lombok 1.18.8                       | 1.18.30+                             | 🟡 顺手             |

### 阶段 2：工程化重构（改善体验，可穿插进行）

1. **模块命名统一** + 根 pom 全聚合（一次提交，纯移动 + artifactId 改名，git 能追踪 rename）
2. **配置收敛**：统一 application.yml；本地可跑默认值 + Nacos 覆盖职责分离；消除三格式并存
3. **凭据治理**：仓库内只留占位符；`.gitignore` 纳入本地私密配置；历史提交清敏感信息（git filter-repo 重写，**老板确认后做**，或至少本轮起不再新增）
4. **补测试**：先补 3 条关键链路集成测试（关单补偿、库存解锁幂等、秒杀防重），再逐步铺单测
5. **CI**：Gitee/GitHub Actions 编译检查 + 依赖漏洞扫描（每 PR 自动体检）
6. **代码风格现代化**（量大，按需渐进）：构造器注入、@RequestMapping 细分 method、R 改造、分页参数对象化——**建议放到最后，避免和版本升级混在一起难排查**
