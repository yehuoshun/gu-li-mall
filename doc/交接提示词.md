## 6. 已知坑（血泪）

1. **语雀 create 只认数字 book_id**：em82l9 = `85213543`（namespace 会报 book not found）
2. **mcporter 大 JSON**：不要 shell 命令替换内嵌（触发 auto-correction 报 Unknown server）→ 用 python subprocess + `json.dumps(args)`
3. **`.idea/` 故意入库**（项目级字典 `dictionaries/project.xml` 共享拼写词汇）——不移除、不忽略（`.iml` 已忽略）
4. **老板常并发推送**：push 前先 `git fetch` + `git rebase origin/main`，被拒是常态
5. **课程旧代码错拼不沿用**：Enume→Enum、VAILD→VALID、INVAILD→INVALID、UNKNOW→UNKNOWN、ACCT→ACCOUNT
6. **md 表格追加行要与整表对齐**；语雀 API 偶发抖动 → 调用带重试
7. **`AutoConfiguration.imports` 是数据源基座唯一的注册入口，勿删**（`MybatisPlusAutoConfiguration` 只标 `@AutoConfiguration`，不参与包扫描）；缺它则分页/乐观锁/防全表/自动填充**静默失效**（编译启动都正常）
8. **删了源码也未必暴露**：Maven 不会清理 `target/classes` 里的旧资源 → 本地"照常能跑"是残留副本造成的假象；**验证前先 `clean`**
9. **`annotationProcessorPaths` 一旦显式声明，classpath 上的处理器不再被扫描** → lombok 必须一并列上，否则 `@Data/@Getter/@Slf4j` 全失效（报「找不到符号 log」）；MPJ processor 同理必须列上，否则 Chain 类静默不生成
10. **本仓库自己的模块不能写进 `annotationProcessorPaths`**（compile 阶段没有 jar，解析必失败）；跨 jar 的自动配置只能靠 7 里那份文件。**nameFix 方案的思路就是「把生成器发布到本地仓库，当第三方处理器用」**
11. **IDEA 的注解处理器配置是从 Maven 导入生成的**（`.idea/compiler.xml` 按模块生成 profile）：改完 pom 必须 **Reload Maven Project**，否则 profile 里只有 lombok → IDE 内不生成 Chain → 满屏「找不到符号 XxxChain」
12. **nameFix 不在 Central**：本地仓库必须先有 `icu/mhb/*/2.1.3-nameFix/`（`mvn install` fork 或用 `tmp/mpj-2.1.3-nameFix.zip`）；fork **只能用 JDK 8 编**（其 lombok 1.18.10 限制）
13. **沙箱 TLS**：出网走中间人代理，JDK cacerts 不认 → 构建要用系统 trustStore（见 `TOOLS.md` 与 `scripts/build-gu-li-mall.sh`）
14. **Spring Cloud Gateway 4.3 属性前缀变了**：`spring.cloud.gateway.*` 全部 deprecated → 用 `spring.cloud.gateway.server.webflux.*`（routes / discovery.locator 都在里面）；`lb://` 路由必须显式引 `spring-cloud-starter-loadbalancer`（Nacos discovery 不再自动带）
15. **Nacos 端口语义**：主端口 8848（1.x/2.x/3.x 都是）；2.x gRPC 9848/9849；**3.0 控制台独立到 8080**（浏览器访问 `:8848/nacos` 在 3.0 不再是控制台）
16. **业务模块的 Web 能力来自 `gu-li-mall-common`**（common 里带 `spring-boot-starter-web`）→ 业务模块必须依赖 common，否则起了也没有 HTTP 端口（Tomcat 不启动、`server.port` 无效、Nacos 注册没端口可报）
17. **gateway 严禁依赖 `gu-li-mall-common`**：common 带 Tomcat/WebMVC，与 Gateway 的 WebFlux 冲突；网关要的公共能力放自己模块内（已加注释锁死）
18. **Nacos 3.x 客户端注册要带账号**：报 `ErrCode:403 ... Code: 401, Message: User not found!` 就是没传 username/password（3.x 默认开鉴权）；yml 里用 `${NACOS_USERNAME:nacos}` / `${NACOS_PASSWORD:nacos}` 占位，改过密码用环境变量覆盖，别把真密码提交进仓库
19. **配置中心（Boot 3 / SCA 2025）三个要点**：① **必须写 `spring.config.import`**，不写就触发 `import-check` 报错（默认开）；② **优先级：本地 `application.yml` > 导入的 Nacos 配置**（Boot 规则：导入文档优先级低于导入它的文档；SCA 另有 `spring.cloud.nacos.config.preference` 默认 `local` 印证）→ **想让 Nacos 覆盖某项，本地就不能写同名键**；③ 用 `optional:` 前缀，Nacos 不可用/配置不存在时降级启动，不报错自杀
20. **dataId / namespace / group 规划**：dataId = `gu-li-mall-common.yaml`（全服务共享）+ `<服务名>.yaml`（单服务专属）；**namespace = 本项目专用命名空间**（`discovery.namespace` 与 `config.namespace` 必须一致，否则注册上了也拉不到配置）；group 继续用默认 `DEFAULT_GROUP`。⚠️ 客户端填的是**命名空间 ID**：本项目实际 ID = `3d97ec1a-816e-48d9-a2ac-b82eca14b6c0`（名称叫 `gu_li_mall`，名字不能当 ID 用）
